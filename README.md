# Cléosio Alfazema de Sousa — Professional Portfolio

A responsive, single-page portfolio website for entry-level IT Support, Technical Support and Cybersecurity Fundamentals roles.

## Files
- `index.html` — complete responsive website, no build tools required.
- `Portfolio_Cléosio_Alfazema_de_Sousa.pdf` — printable portfolio profile.

## Preview locally
Open `index.html` in any modern web browser.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account: https://github.com/
2. Create a public repository named `cleosio-alfazema-de-sousa.github.io`.
3. Upload `index.html` to the repository root and commit the change.
4. In repository Settings → Pages, select the main branch and root folder if prompted.
5. Wait for GitHub Pages to publish the site. The usual address will be `https://YOUR-USERNAME.github.io/`.
6. Replace `YOUR-USERNAME` with your actual GitHub username; do not share a guessed URL as if it were live.

## Before publishing
- Check every certificate title/date against the original certificates.
- Add LinkedIn and GitHub URLs once you have created those profiles.
- Complete the planned labs before presenting them as completed projects.
- Never upload passwords, private customer data, IP addresses from private networks, or other sensitive information.
